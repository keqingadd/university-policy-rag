# 智擎云 AI 中台产品概览

## 产品定位
智擎云 AI 中台（ZhiQing Cloud，简称 ZQC）是面向中大型企业的模型应用平台，帮助企业在不自建 GPU 集群的前提下，把大模型能力接入业务系统。当前版本为 3.2，主要面向金融、制造、政务、零售四类客户。

## 核心模块
智擎云包含五个核心模块：

1. 数据接入：支持 PDF、Word、Markdown、TXT、HTML 等文档批量导入，内置 OCR 处理扫描件。
2. 知识库问答（RAG）：对文档做切片、向量化与混合检索，并提供带引用溯源的问答接口。
3. 模型服务：统一封装 DeepSeek、通义、智谱等模型，提供 OpenAI 兼容的调用协议。
4. Agent 编排：支持工具调用、多步任务编排与人工审核节点。
5. 运营看板：统计调用量、命中率、平均响应时间和幻觉率。

## 典型场景
- 客服知识库：坐席在对话中实时检索产品政策与售后条款。
- 新员工培训：新人对内部制度提问，系统给出带出处的答案。
- 售后工单辅助：根据工单描述推荐处理方案，并附上历史相似工单。
